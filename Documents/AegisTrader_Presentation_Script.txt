SECTION 1: THE GENERALIZED PROBLEM STATEMENT (1 Minute)
--------------------------------------------------------------------------------
"Respected evaluators, good morning/afternoon.

Imagine learning how to fly an airplane. You wouldn't jump straight into a real 
aircraft without practicing in a flight simulator first. Financial trading is 
exactly the same—before risking real money, people need a virtual sandbox simulator 
to test their trading ideas on historical market data. This process is called BACKTESTING.

However, existing free or student-accessible trading simulators have 4 MAJOR SOFTWARE FLAWS:

1. THE 'CHEATING' PROBLEM (LOOKAHEAD BIAS):
   Many existing tools accidentally leak future price data to the user while replaying past events. 
   It’s like taking an exam when you can already see tomorrow's answer key—it creates fake success.

2. UNREALISTIC WIN SIMULATION:
   When financial markets move violently in a single second, legacy tools optimistically assume 
   the user won money, ignoring real-world delays and price slippage where real traders lose money.

3. SLOW & HEAVY DATABASES (DATA DUPLICATION):
   To show price charts in different views (1-minute, 15-minute, 1-hour), existing systems copy and 
   store the same data 5 times over millions of database rows, causing severe database storage bloat 
   and slow performance.

4. HIGH DATA SUBSCRIPTION COSTS:
   Real-time live market price feeds are locked behind expensive commercial subscription APIs, 
   making realistic live practice unaffordable for students and retail traders."


--------------------------------------------------------------------------------
SECTION 2: THE PROPOSED SOLUTION — AEGISTRADER (1 Minute)
--------------------------------------------------------------------------------
"To solve these challenges, I engineered AEGISTRADER—a web-based 'Flight Simulator for 
Financial Trading' built using modern full-stack software development principles.

How AegisTrader Solves Each Problem:

• STRICT ANTI-CHEATING REPLAY CLOCK:
  Our backend enforces an absolute database time barrier (Timestamp <= CurrentReplayTime). 
  The system mathematically guarantees that the chart CANNOT see even a single millisecond into the future.

• REALISTIC RISK ENGINE:
  If market prices move violently across a user's target limits, our execution engine defensively 
  simulates real-world loss scenarios instead of giving fake wins.

• SMART ON-THE-FLY DATA AGGREGATION:
  Instead of duplicating database tables, our backend algorithm uses integer epoch math to 
  dynamically convert 1-minute historical data into 5m, 15m, 1H, and 4H charts on-the-fly, 
  saving over 80% database storage.

• FREE REAL-TIME LIVE DATA BRIDGE:
  We built a lightweight Python bridge that connects to live market terminals and streams 
  real-time price updates into our web app every half second at zero API cost."


--------------------------------------------------------------------------------
SECTION 3: SOFTWARE ARCHITECTURE & TECH STACK (1 Minute)
--------------------------------------------------------------------------------
"AegisTrader is designed as a decoupled, 4-tier web application:

1. FRONTEND USER INTERFACE:
   Built with React 19 and TradingView Charting Library for smooth, dark-mode financial charts.

2. BACKEND API SERVICE:
   Built with ASP.NET Core 10 Web API. It handles authentication using encrypted passwords 
   (BCrypt) and secure login keys (JWT Tokens).

3. BUSINESS LOGIC SERVICES:
   Specialized backend C# services for time-barrier filtering, instant data aggregation, 
   virtual trade execution, and performance scoring.

4. DATABASE & DATA FEED:
   PostgreSQL 16 relational database indexing over 1,000,000 historical price records, 
   paired with a local Python script streaming live price feeds."
