SECTION 1: THE PROBLEM STATEMENT (1 Minute)
--------------------------------------------------------------------------------
"Respected evaluators, good morning/afternoon.

In quantitative financial trading—specifically frameworks like Inner Circle Trader (ICT) 
and Smart Money Concepts (SMC)—traders rely heavily on backtesting historical data 
and forward-testing strategies before risking real capital.

However, existing retail backtesting platforms suffer from 4 critical technical flaws:

1. LOOKAHEAD BIAS: Legacy simulators lack an absolute timestamp barrier, allowing future 
   candlesticks to leak into the chart view during backtesting, invalidating test results.
2. FLAWED EXECUTION MODELING: When market volatility causes a single bar's range to breach 
   BOTH Take Profit (TP) and Stop Loss (SL) levels, existing systems optimistically register 
   a winning trade rather than simulating realistic adverse slippage.
3. DATABASE BLOAT: Generating higher timeframes (5m, 15m, 1H, 4H) traditionally requires 
   maintaining duplicate, pre-calculated database tables for every interval, causing massive 
   storage bloat over millions of rows.
4. HIGH COST & PROPRIETARY FEEDS: Commercial live price APIs require expensive subscription 
   fees, making real-time testing inaccessible for retail developers."


--------------------------------------------------------------------------------
SECTION 2: THE PROPOSED SOLUTION — AEGISTRADER (1 Minute)
--------------------------------------------------------------------------------
"To solve these challenges, I built AEGISTRADER — a full-stack, enterprise-grade trading 
simulation platform engineered for zero-risk strategy validation.

Key Architectural Solutions:
• Deterministic Replay Engine: Enforces a strict database query boundary 
  (Timestamp <= CurrentReplayTimestamp) to mathematically guarantee zero-lookahead bias.
• Dynamic Server-Side MTF Aggregation: Uses Unix Epoch integer division to generate 
  5m, 15m, 1H, and 4H charts on-the-fly directly from 1-minute historical data without 
  duplicate tables.
• Defensive Overlap Constraint: Implements a pessimistic execution model—if a single 
  bar hits both SL and TP, the engine forces a Stop Loss closure to mirror real slippage.
• Zero-Cost Real-Time MT5 Bridge: Integrates a local Python bridge using the MetaTrader 5 
  SDK to stream live 500ms tick prices from a Vantage Markets terminal into the API."


--------------------------------------------------------------------------------
SECTION 3: TECHNICAL ARCHITECTURE & STACK (1.5 Minutes)
--------------------------------------------------------------------------------
"AegisTrader follows a clean Controller-Service-Repository architecture split across 4 tiers:

1. FRONTEND LAYER: Built with React 19, Vite 8, Tailwind CSS v4, and TradingView 
   Lightweight Charts v5 for responsive visual canvas rendering.
2. WEB API LAYER: ASP.NET Core 10 Web API providing RESTful JSON endpoints protected by 
   JWT Bearer authentication and BCrypt password hashing.
3. BUSINESS LOGIC SERVICES:
   - ReplayService: Manages the anti-lookahead historical clock.
   - AggregationService: Performs server-side integer-division MTF candle grouping.
   - TradeService: Handles 5-decimal Forex pip math, dynamic floating PnL, and SL/TP hits.
   - AnalyticsService: Calculates quantitative metrics over closed trades.
   - LivePriceCache: In-memory thread-safe tick buffer updating at 500ms intervals.
4. PERSISTENCE & DATA FEED: PostgreSQL 16 database with EF Core 10 migrations. Financial 
   decimals mapped to decimal(18,6) with composite B-Tree indexing on (Symbol, Timestamp) 
   to query over 1,000,000 Dukascopy historical records in sub-milliseconds."
